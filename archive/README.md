# archive

这里存放的是开发过程中产生的**临时调试记录、工具输出和厂商手册**，不属于工程源码。
保留是为了以后回溯，日常开发不需要看。

| 内容 | 说明 |
|---|---|
| `_*.txt` | 串口/CAN/OpenOCD/构建等过程的调试记录 |
| `build_log.txt` / `flash_log.txt` | 构建和烧录日志 |
| `_zdt_manual.pdf` | 张大头 ZDT X42S 闭环步进电机用户手册 |

工程源码在仓库根目录的 `Core/`、`Drivers/`、`cmake/` 下，使用说明见根目录 `README.md`。
